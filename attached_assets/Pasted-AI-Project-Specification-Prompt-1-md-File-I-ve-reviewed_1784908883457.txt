I've reviewed the uploaded prompt. It is a structured, two-step prompt template for generating a complete software project specification and roadmap.

The prompt is well organized and production-oriented. A few observations:

Strengths
Covers the entire software planning lifecycle from idea validation to architecture.
Forces the AI to ask clarifying questions instead of making assumptions.
Encourages recommendations instead of simply listing options.
Includes architecture, database, API, security, deployment, testing, monitoring, backups, and cost estimation.
Produces a reusable specification that can be handed to another AI.
Areas I'd Improve

AI Guidance
Ask the AI to avoid overengineering.
Prefer modular monolith before microservices.
Recommend battle-tested libraries.
Explain trade-offs whenever choosing technologies.
One Important Change

I'd also change the workflow slightly.

Instead of:

Questions
↓
Recommendations
↓
Specification

I'd use:

Understand Idea
↓
Identify Risks
↓
Ask Questions
↓
Recommend Best Architecture
↓
Finalize Decisions
↓
Generate Specification
↓
Generate Development Roadmap

This produces better architectural decisions because risks are identified before recommendations.
